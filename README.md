# About

This is a terminal-based finance dashboard, it's meant to be more of a display piece.

It was developed against a headless RPi but you can also just maximize a terminal from a desktop and run this app directly.

## Install dependencies

These deps are primarily for the display on a headless setup

- `$cd src`
- `$chmod +x install-deps.sh`
- `$./install-deps.sh`

## Run

- `$chmod +x openbox`
- `sudo xinit ./openbox`
